# S08 — SMA Perfect Order BOTH Signal

USDJPY 4 時間足チャート上で「SMA 20 / 50 / 200 のパーフェクトオーダーが完成した瞬間」をエッジトリガーで矢印表示する Forex Tester 6 用カスタムインジケータ。SMA20 > SMA50 > SMA200 の上向き整列が成立した足に緑の上向き矢印（BUY）、SMA20 < SMA50 < SMA200 の下向き整列が成立した足に赤の下向き矢印（SELL）を立てます。

## 元記事

[USDJPY 4 時間足 パーフェクトオーダー検証 — トレーダーの処方箋](https://traders-rx.com/usdjpy-h4-perfect-order/)

過去 8 年（2018〜2026 年 4 月）の検証結果:
- **プロフィットファクター 1.25、シャープレシオ 1.62、勝率 34.3%、累計 +1,470 pip（178 トレード）**

## 表示される内容

- SMA 20（赤実線）
- SMA 50（青実線）
- SMA 200（緑実線）
- BUY シグナル（緑の上向き矢印）— SMA20 > SMA50 > SMA200 が当足で初めて成立（エッジトリガー）
- SELL シグナル（赤の下向き矢印）— SMA20 < SMA50 < SMA200 が当足で初めて成立（エッジトリガー）

矢印は「シグナル足」（パーフェクトオーダーが完成した足）を示します。記事のエントリーは「シグナル足の終値」または「翌足の始値」で運用してください。

エッジトリガーは「前足まで未成立 → 当足で初めて成立」を意味します。整列が継続している局面では、最初の足にだけ矢印が立ちます。

損切り・利確のラインは描画しません。記事本文の **SL = 50 pip / TP = 120 pip（RR 2.4）** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で「当足の SMA200」と「1 本前の足の SMA200」を参照するため、起動時点から **確定足が 202 本** 揃うまで線も矢印も表示されません。USDJPY の H4 でいうとおおむね **1.5 ヶ月** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | USDJPY（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | H4 |
| シグナル種別 | BUY / SELL（両方向） |
| エッジトリガー (BUY) | SMA20 > SMA50 > SMA200 が当足で初めて成立 |
| エッジトリガー (SELL) | SMA20 < SMA50 < SMA200 が当足で初めて成立 |
| 表示までに必要な確定足 | 202 本（USDJPY H4 で約 1.5 ヶ月） |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。なお [GBPUSD 4 時間足版 (S01)](../S01_gbpusd_h4_perfect_order/) は同じロジック（パラメータ同一）で PF 1.22 と、ほぼ同じ結果を示しています。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `SMA_PerfectOrder_BothSignal-s08-v1.0.0.zip` をダウンロード
2. ZIP を展開
3. `SMA_PerfectOrder_BothSignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → USDJPY H4 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「PerfectOrder BOTH (USDJPY H4)」を選択
