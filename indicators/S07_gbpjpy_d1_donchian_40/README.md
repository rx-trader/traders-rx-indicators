# S07 — Donchian-40 BOTH Signal

GBPJPY 日足チャート上で「直近 40 日 Donchian チャネルブレイク」のエッジトリガーを矢印で表示する Forex Tester 6 用カスタムインジケータ。前日までの 40 日高値を Close が上抜けた足に緑の上向き矢印（BUY）、前日までの 40 日安値を Close が下抜けた足に赤の下向き矢印（SELL）を立てます。

## 表示される内容

- Donchian(40) 高値（オレンジ実線）— 前日までの 40 日高値
- Donchian(40) 安値（オレンジ実線）— 前日までの 40 日安値
- BUY シグナル（緑の上向き矢印）— Close が前日までの 40 日高値を上抜けた足（エッジトリガー）
- SELL シグナル（赤の下向き矢印）— Close が前日までの 40 日安値を下抜けた足（エッジトリガー）

矢印は「シグナル足」（ブレイクが発生した足）を示します。記事のエントリーは「翌足の始値」です。

エッジトリガーは「前日まで未ブレイク → 当日初めてブレイク」を意味します。同方向のブレイクが連続する局面では、初日だけに矢印が立ちます。

損切り・利確のラインは描画しません。記事本文の **SL = 100 pip / TP = 250 pip（RR 2.5）** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で「前日までの 40 本」と「2 日前までの 40 本」の高値・安値を参照するため、起動時点から **確定足が 42 本** 揃うまで線も矢印も表示されません。GBPJPY の D1 でいうとおおむね **2 ヶ月** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | GBPJPY（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | D1 |
| シグナル種別 | BUY / SELL（両方向） |
| エッジトリガー (BUY) | Close > 前日までの 40 日高値 かつ 前足では未ブレイク |
| エッジトリガー (SELL) | Close < 前日までの 40 日安値 かつ 前足では未ブレイク |
| 表示までに必要な確定足 | 42 本（GBPJPY D1 で約 2 ヶ月） |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `Donchian40_BothSignal-s07-v1.0.0.zip` をダウンロード
2. ZIP を展開
3. `Donchian40_BothSignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → GBPJPY D1 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「Donchian-40 BOTH (GBPJPY D1)」を選択
