# S09 — Asia Range / London Break BOTH Signal

USDJPY 1 時間足チャート上で「アジア時間（UTC 0-6）のレンジ高値・安値を、ロンドン時間（UTC 8-11）の終値が初めてブレイクした瞬間」をエッジトリガーで矢印表示する Forex Tester 6 用カスタムインジケータ。終値がアジア高値を上抜けた足に緑の上向き矢印（BUY）、終値がアジア安値を下抜けた足に赤の下向き矢印（SELL）を立てます。

## 表示される内容

- アジア高値（オレンジのステップライン、UTC 7〜14 のみ描画）
- アジア安値（オレンジのステップライン、UTC 7〜14 のみ描画）
- BUY シグナル（緑の上向き矢印）— ロンドン時間（UTC 8-11）の終値が当足で初めてアジア高値を上抜け（エッジトリガー）
- SELL シグナル（赤の下向き矢印）— ロンドン時間（UTC 8-11）の終値が当足で初めてアジア安値を下抜け（エッジトリガー）

矢印は「シグナル足」（ブレイクが成立した足）を示します。記事のエントリーは「シグナル足の終値」または「翌足の始値」で運用してください。

エッジトリガーは「前足まで未ブレイク → 当足で初めてブレイク」を意味します。同方向のブレイクが連続する場合は、最初の足にだけ矢印が立ちます。

### レンジサイズフィルター

アジアレンジ（高値−安値）が **直近 14 本の平均レンジ × 0.5 を下回る日** は、レンジが小さすぎてだましが多いためシグナルを出しません（矢印は表示されません）。元記事の検証もこのフィルターを適用しています。

損切り・利確のラインは描画しません。記事本文の **SL = 反対側のアジアレンジ端 ± ATR × 0.5 / TP = レンジサイズ × 1.5 / TimeStop 10 時間** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で「直近 14 本の平均レンジ」と「24 時間以内のアジア時間バー」を参照するため、起動時点から **確定足が約 40 本** 揃うまで矢印が表示されないことがあります。USDJPY の H1 でいうとおおむね **1.5 〜 2 営業日** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | USDJPY（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | H1 |
| シグナル種別 | BUY / SELL（両方向） |
| アジアレンジ定義 | UTC 0-6（7 本）の高値・安値 |
| エントリーウィンドウ | UTC 8-11（4 本）|
| レンジサイズフィルター | アジアレンジ ≥ 直近 14 本の平均レンジ × 0.5 |
| エッジトリガー (BUY) | 終値 > アジア高値（前足まで未ブレイク → 当足で初めて成立） |
| エッジトリガー (SELL) | 終値 < アジア安値（前足まで未ブレイク → 当足で初めて成立） |
| アジア高値・安値ライン描画 | UTC 7〜14 のみ |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `AsiaRange_LondonBreak_BothSignal-s09-v1.0.0.zip` をダウンロード
2. ZIP を展開
3. `AsiaRange_LondonBreak_BothSignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → USDJPY H1 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「AsiaRange/LondonBreak BOTH (USDJPY H1)」を選択
