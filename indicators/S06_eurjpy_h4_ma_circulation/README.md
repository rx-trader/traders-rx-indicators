# S06 — MA Stage 2/5 BOTH Signal

EURJPY H4 チャート上で「MA 大循環 ステージ 2/5 完成 × 日足 SMA50 トレンドフィルター」のエッジトリガーを矢印で表示する Forex Tester 6 用カスタムインジケータ。日足 SMA50 のトレンドは H4 上で SMA(300) を使って近似しています（5 日前比＝ 30 H4 bars 前比）。

## 元記事

[EURJPY 4 時間足 MA 大循環ステージ 2/5 検証 — トレーダーの処方箋](https://traders-rx.com/eurjpy-h4-ma-circulation/)

過去 8 年（2018〜2026 年 4 月）の検証結果:
- MA 大循環単体: プロフィットファクター 1.07、勝率 30.0%、累計 +1,290 pip
- **改良案（日足 SMA50 トレンドフィルター付き）**: プロフィットファクター 1.22、勝率 32.7%、累計 +1,860 pip

本インジケータは **改良案のエントリーシグナル** を表示します。

## ダウンロード

最新版は **[Releases ページ](https://github.com/rx-trader/traders-rx-indicators/releases)** から `.zip` を取得してください。

## 表示される内容

- SMA(5)（黄色） / SMA(20)（青） / SMA(40)（マゼンタ）の 3 本 — 大循環判定用
- SMA(300)（グレー実線、太線）— 日足 SMA50 を H4 上で近似
- BUY シグナル（緑の上向き矢印）— SMA5 > SMA20 > SMA40 が完成 かつ SMA(300) が 30 H4 bars 前より上向き
- SELL シグナル（赤の下向き矢印）— SMA5 < SMA20 < SMA40 が完成 かつ SMA(300) が 30 H4 bars 前より下向き

矢印は「シグナル足」（整列が完成した足）を示します。記事のエントリーは「翌足の始値」です。

損切り・利確のラインは描画しません。記事本文の **SL = 60 pip / TP = 150 pip（RR 2.5）** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で SMA(300) と「SMA(300) の 30 本前の値」を計算するため、起動時点から **確定足が 331 本** 揃うまで線も矢印も表示されません。EURJPY の H4 でいうとおおむね **55 営業日（約 11 週間）** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | EURJPY（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | H4 |
| シグナル種別 | BUY / SELL（両方向） |
| エッジトリガー (BUY) | SMA5 > SMA20 > SMA40 が当該足で初めて成立 かつ SMA(300) > SMA(300)[30 H4 bars 前] |
| エッジトリガー (SELL) | SMA5 < SMA20 < SMA40 が当該足で初めて成立 かつ SMA(300) < SMA(300)[30 H4 bars 前] |
| 表示までに必要な確定足 | 331 本（EURJPY H4 で約 55 営業日） |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

トレンドフィルターは「H4 上の SMA(300) が 30 H4 bars 前より上向き／下向き」を判定基準にしています。30 H4 bars ≒ 5 D1 bars ＝ 5 日前比なので、記事本文の「日足 SMA50 が 5 日前より上向き／下向き」と同じトレンド判定です。同じ EURJPY H4 データでの A/B 検証で、両者の PF 差は 0.011（誤差 1% 以内）に収まることを確認しています。

他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `MA_Stage_BothSignal-s06-v1.1.0.zip` をダウンロード
2. ZIP を展開
3. `MA_Stage_BothSignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → EURJPY H4 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「MA Stage 2/5 BOTH (EURJPY H4)」を選択
