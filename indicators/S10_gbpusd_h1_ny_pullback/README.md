# S10 — NY DayHigh / EMA20 Pullback BUY Signal

GBPUSD 1 時間足チャート上で「NY 時間（UTC 13-20）に、当日高値圏まで伸びた相場が EMA20 を一度割ってから当足で再び上抜けた瞬間（押し目からの再加速）」をロング専用のシグナルとして矢印表示する Forex Tester 6 用カスタムインジケータ。条件が同時に成立した足にピンクの上向き矢印（BUY）を立てます。

## 表示される内容

- EMA20（青のライン）
- 当日高値（シアンのステップライン、当日 00:00 からの累積最高値）
- BUY シグナル（ピンクの上向き矢印）— NY 時間（UTC 13-20）に、当日高値圏で、前足終値が EMA20 を下回り当足終値が EMA20 を上回った（1 本での上抜け）足

矢印は「シグナル足」を示します。記事のエントリーは「シグナル足の終値」または「翌足の始値」で運用してください。ロング専用です。

### 当日高値圏フィルター

当日高値（当日 00:00 からの累積最高値）と終値の差が **直近 14 本の平均レンジ（高値−安値）× 0.5 を上回る** 場合は、高値圏から離れすぎているとしてシグナルを出しません（矢印は表示されません）。元記事の検証もこのフィルターを適用しています。

損切り・利確のラインは描画しません。記事本文の **SL = 90 pip / TP = 180 pip / TimeStop 48 時間** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で「EMA20」「直近 14 本の平均レンジ」「当日 00:00 からの累積高値」を参照するため、起動時点から **確定足が約 40 本** 揃うまで矢印が表示されないことがあります。GBPUSD の H1 でいうとおおむね **1.5 〜 2 営業日** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | GBPUSD（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | H1 |
| シグナル種別 | BUY のみ（ロング専用） |
| エントリーウィンドウ | UTC 13-20（NY 時間） |
| 当日高値定義 | 当日 00:00 からの累積最高値 |
| 当日高値圏フィルター | \| 当日高値 − 終値 \| ≦ 直近 14 本の平均レンジ × 0.5 |
| エントリー条件 | 前足終値 < EMA20 かつ 当足終値 > EMA20（1 本での EMA20 上抜け） |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `NY_DayHigh_EMA20_BuySignal-s10-v1.0.0.zip` をダウンロード
2. ZIP を展開
3. `NY_DayHigh_EMA20_BuySignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → GBPUSD H1 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「NY DayHigh EMA20 Pullback BUY (GBPUSD H1)」を選択
