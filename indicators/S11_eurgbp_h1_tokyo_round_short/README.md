# S11 — Tokyo Round-Number SELL Signal

EURGBP 1 時間足チャート上で「東京時間（UTC 0-6）に、EMA が上昇配列（EMA20 > EMA50 > EMA100、かつ終値 > EMA20）の状態で、その足の高値・安値が 0.0050 刻みのラウンドナンバーを跨いだ瞬間」をショート専用のシグナルとして矢印表示する Forex Tester 6 用カスタムインジケータ。条件が同時に成立した足に赤の下向き矢印（SELL）を立てます。上昇トレンド中のラウンドナンバー到達で起きやすい一時的な反落を取りにいく逆張り風ロジックです。

## 表示される内容

- EMA20（赤のライン）
- EMA50（青のライン）
- EMA100（紫のライン）
- SELL シグナル（赤の下向き矢印）— 東京時間（UTC 0-6）に、EMA20 > EMA50 > EMA100 かつ終値 > EMA20 の上昇配列で、その足の高値・安値が 0.0050 刻みのラウンドナンバーを跨いだ足

矢印は「シグナル足」を示します。記事のエントリーは「シグナル足の終値」または「翌足の始値」で運用してください。ショート専用です。

### ラウンドナンバー水平線について

このインジケータが描画するのは EMA 3 本と矢印だけです。0.0050 刻みのラウンドナンバー水平線（0.8500 / 0.8550 / 0.8600 …）は、元記事の手順どおりチャートにご自身で引いてください。矢印がどのラウンドナンバーを跨いだ瞬間に立ったのかを目で確認しやすくなります。

### エッジトリガー

東京時間・EMA 上昇配列・ラウンドナンバー通過の 3 つが同時に成立し、かつ **前足では未成立だった**（エッジトリガー）足にだけ矢印が立ちます。条件が連続する局面でも、最初の足にだけ矢印が表示されます。

損切り・利確のラインは描画しません。記事本文の **SL = 90 pip / TP = 180 pip（RR 2.0）/ TimeStop 48 時間** ルールをご自身で適用してください。

## 表示までに必要な確定足の本数

このインジケータは内部で EMA20 / EMA50 / EMA100 を参照するため、起動時点から **確定足がおおむね 100 本** 揃うまで矢印が表示されないことがあります。EURGBP の H1 でいうとおおよそ **4 〜 5 営業日** 分です。新しいチャートを開いた直後は左端近辺にインジが描画されないので、十分過去まで遡ってロードしてください。

## 仕様

| 項目 | 内容 |
|---|---|
| 対象通貨ペア | EURGBP（記事のバックテストはこの通貨ペアでのみ実施） |
| 対象時間足 | H1 |
| シグナル種別 | SELL のみ（ショート専用） |
| エントリーウィンドウ | UTC 0-6（東京時間） |
| EMA 配列条件 | EMA20 > EMA50 > EMA100 かつ 終値 > EMA20 |
| ラウンドナンバー判定 | 当該足の高値・安値が 0.0050 刻みの境界を跨ぐ |
| トリガー | エッジトリガー（前足は未成立 → 当足で初めて成立） |
| 損切り・利確 | 描画しない（記事ルールに従い手動運用） |

「EMA 上昇配列でショート」は直感に反しますが、これは上昇トレンド中のラウンドナンバー到達で起きやすい一時的な反落を取りにいく逆張りロジックです。EURGBP の長期レンジ性 × 東京時間の薄い流動性 × 0.0050 ラウンドナンバーの心理的節目という 3 つの構造的要因が重なって edge を生んでいます。他の通貨ペア・時間足でもチャートに追加することは可能ですが、その場合のバックテスト結果は保証されません。

## インストール

[当ブログのチュートリアル記事](https://traders-rx.com/install-traders-rx-indicators/) を参照してください。

要点のみ:

1. Release ページから `Tokyo_RoundNumber_SellSignal-s11-v1.0.0.zip` をダウンロード
2. ZIP を展開
3. `Tokyo_RoundNumber_SellSignal.dll` を Forex Tester 6 のインストール場所内の `Indicators` フォルダにコピー
   （標準インストール例：`C:\ForexTester6\Indicators\`）
4. Forex Tester 6 を再起動 → EURGBP H1 チャート → 右クリック → 「インジケータを追加」→「カスタム」→「Tokyo Round-Number SELL (EURGBP H1)」を選択
